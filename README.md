# Иллюстрации в едином стиле

Навык Codex: [consistent-illustrations](.agents/skills/consistent-illustrations/SKILL.md).

Вызов в задаче, где доступен этот репозиторий:

```text
$consistent-illustrations Нарисуй небольшую мастерскую в старом городе на закате.
```

Навык использует сцену из текущего запроса, четыре встроенных визуальных образца, горизонтальный формат 16:9, низкую детализацию, мягкий свет и естественную асимметрию. По умолчанию аниме запрещено. Персонажи и композиции образцов не переносятся в новую сцену автоматически.

## Необходимые файлы

Текст навыка подготовлен. Пакет пока не завершён: исходные изображения, показанные в чате, ещё не доступны как файлы. Перед использованием нужно добавить в `.agents/skills/consistent-illustrations/assets/` четыре оригинала в порядке прикрепления:

1. `style-reference-1.png` — крупный план персонажа в синем плаще в ночном лесу.
2. `style-reference-2.jpg` — персонаж на кровати обнимает подушку.
3. `style-reference-3.jpg` — персонаж сидит на краю кровати у окна.
4. `style-reference-4.jpg` — персонаж в лесу, рука у подбородка.

Расширение должно соответствовать реальному формату файла. При необходимости изображения следует перекодировать без изменения рисунка и обновить пути в навыке. Не создавать подменные образцы генерацией.

Для использования в другом проекте скопируйте всю папку `consistent-illustrations`, включая `assets`, в `.agents/skills/` этого проекта. Доступность навыка в текущем интерфейсе зависит от загрузки навыков из репозитория; создание файлов не устанавливает глобальный навык в ChatGPT.

Старые материалы Practice удалены отдельным коммитом. Они остаются доступны в истории Git.
